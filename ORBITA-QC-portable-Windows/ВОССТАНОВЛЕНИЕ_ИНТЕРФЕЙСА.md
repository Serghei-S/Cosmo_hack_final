# Восстановление интерфейса ОРБИТА.QC

## Проверенные источники

- `source/src/views.tsx`, `source/src/navigation.ts`, `source/src/App.tsx`, `source/src/ui.tsx`, `source/src/styles.css`, `source/src/assets/planet-orbita.webp`: сохранившийся ролевой концепт и компоненты.
- `КАРТА_СИСТЕМЫ.md`: пять рабочих мест, 16 пространств, 61 вкладка, контекстные переходы, паспорт, поиск, фильтр смен и URL состояния.
- `ORBITA-QC-full-data.zip`: архив датасета без интерфейса. `ORBITA-QC-workspaces-Windows.zip` содержал уже изменённую сборку. Отдельного архива прежнего интерфейса и истории Git в папке нет.

## Прежняя структура по ролям

Общее для пяти ролей: боковое меню с двумя группами и картой приложения, верхняя панель линии с поиском Ctrl+K, уведомлениями и переключением роли, хлебные крошки, фильтр смен, вкладки внутри пространства, паспорт изделия с вкладками «Обзор», «История», «Наблюдения», «Решения», «Состав» (у технолога и администратора ещё «Исходные события»), переходы из таблиц и карточек, адаптивное меню.

## Регрессия после подключения данных

| Было в ролевом концепте | Что подменилось | Восстановление |
| --- | --- | --- |
| Пять отдельных главных экранов: рольная история, планета, 4 показателя, две колонки с карточками, сквозной маршрут, паспорт в фокусе | Один общий короткий экран `LiveHome`; планета перестала выводиться | Вернуть `HomeView` с существующим `planet-orbita.webp` и считать его данные из текущего журнала |
| Контроль качества: разные экраны и вкладки, фильтры случаев, таблицы, повторный контроль и оформленные решения | Почти все вкладки выводили одну очередь; решения получили упрощённую таблицу | Вернуть исходные экраны, встроить умную очередь в «Сигналы» |
| Задачи: рабочий список, команда и отдельная проектная вкладка уведомлений | Все вкладки выводили одну очередь | Вернуть вкладки, добавить очередь к рабочему списку, сохранить «Уведомления» как запланированное |
| Реестр изделий: поиск, состав, текущий статус, переходы в паспорт | Таблица из четырёх колонок без прежних элементов | Вернуть исходный `ProductsView` с текущими проекциями |
| Поток событий: отдельные журнал, качество данных и сценарии | Одинаковый длинный экран на всех трёх вкладках | Разнести живой приём по прежним вкладкам, сохранив таблицы, метрики и управление демопотоком |
| Сравнение «до / после» у технолога | Старый текст утверждал, что исходных изображений нет | Показать реальные доступные фото в прежних карточках, оставив честную заглушку при отсутствии кадра |

Боковое меню, верхняя панель, вкладки, паспорт, переходы и большинство остальных экранов сохранились в исходниках, поэтому их не требуется перерисовывать. Работа по восстановлению изменяет маршрутизацию и интеграцию данных, а не заменяет концепт новым дизайном.

## Последующее изменение по запросу пользователя

В пространстве «Изделия» убраны вкладки «Состав и сборки» и «Прослеживаемость». Один оставшийся реестр показывается без строки вкладок. Состав и история конкретного экземпляра доступны через его паспорт; перечень выше фиксирует исходный ролевой концепт до этого изменения.
